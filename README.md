# Neo Layer Composer v0.1.1

Forge Neoのimg2img内で、背景に透過キャラを重ねて構図を作る拡張機能です。
本体ファイルの変更や追加Pythonライブラリは不要です。画像編集はブラウザー内で行います。

## 使い方

1. `img2img → Generation → img2img` の参考画像の下にある **レイヤー合成** を開きます。
2. **背景を読み込む** で背景画像を選びます。空の編集画面へ画像をドロップしても開始できます。
3. 切り抜いた透過PNGを編集画面へドロップします。**キャラを追加** から複数ファイルも選べます。
4. キャラをドラッグで移動します。四隅のハンドルで縦横比を保って拡大縮小、上側の丸で回転できます。
5. **i2iへ反映** を押し、上の標準参考画像に合成結果が表示されたことを確認します。
6. プロンプト・Denoising strengthを設定し、通常の **生成** を押します。既定では「反映時に生成サイズも合わせる」が有効で、背景の実サイズが幅・高さに入り、Resize toへ切り替わります。別の生成サイズを使う場合はチェックを外してください。

レイヤーを編集したあとは、もう一度 **i2iへ反映** を押してください。生成ボタンだけでは未反映の編集は送られません。
背景のピクセルサイズで合成します。生成サイズが背景と異なる縦横比だと、i2iのリサイズ設定に応じて変形・切り取りが発生します。

## 編集操作

- キャラ最大40枚、重なり順・表示切替・位置の固定に対応。背景は固定です。
- X/Yはキャラの見える範囲の中心座標。サイズは元画像のキャラ部分に対する倍率です。
- 透明余白は操作枠から除外します。元画像のRGBAデータは保持します。
- 数値入力で位置・サイズ・角度を調整、左右反転、回転リセット、中央配置ができます。
- キャンバスにフォーカスして矢印キーで1px、Shift＋矢印で10px移動します。
- 回転ドラッグ中のShiftで15°刻みにします。
- 元に戻す・やり直すは最大50段階。Ctrl+Z / Ctrl+Y / Ctrl+Shift+Zでも操作できます。
- **拡大編集** で作業領域を広げられます。Escで通常表示に戻ります。
- **i2iの画像を背景に** で標準参考画像から背景を取り込めます。
- **レイヤーを初期化** で背景・全キャラ・標準i2i参考画像を消してやり直せます。**元に戻す** でレイヤーを復元し、**i2iへ反映** で参考画像に戻せます。
- 背景を別サイズの画像に交換すると、キャラの中心を新しい背景の比率に合わせ、倍率を幅の比率で調整します。

## 保存

**編集を保存** は、背景・透過画像の元データと各レイヤーの位置・倍率・回転・反転・表示・固定状態を含む `neo-layers.json` をダウンロードします。**編集を開く** で再開できます。別名で複数保存すれば構図の候補を残せます。

**合成PNGを保存** は、レイヤーを1枚に合成したPNGです。編集ファイルと両方残すと便利です。
保存先はブラウザーのダウンロード設定に従います。PNGだけではレイヤーには戻せません。
編集履歴はファイルには含まれません。ページを閉じる前に編集ファイルを保存してください。

透過背景を読み込んだ場合、合成の最下層は白です。PNG/JPEG/WebPに対応し、画像1枚あたり40MB・2,400万画素まで、編集ファイルは200MBまでを目安として検査します。

## 導入・無効化

Neoの **拡張機能 → URLからインストール** に、次のURLを入力してインストールします。

```text
https://github.com/dr1610/neo-layer-composer
```

インストール後はNeoを再起動し、ブラウザーを再読み込みしてください。

手動で導入する場合：

1. `neo-layer-composer` フォルダーをNeoの `extensions` 直下へ配置します。
2. Neoを再起動し、ブラウザーを再読み込みします。
3. Neoの「拡張機能」から本拡張を無効にすると、次の適用・再起動後にパネルが消えます。

サーバー側の追加処理や自動モデル取得はありません。

更新前には **編集を保存** で作業を残してください。URLから導入した場合はNeoの拡張機能画面から更新できます。ZIPで導入した場合は、新しいファイルで拡張フォルダーを更新してください。

## 検証と範囲

Windows / Forge Neo 2.29 / Gradio 4.40.0 / RTX 5070で検証しました。
v0.1.1では状態・描画計算の自動テスト10件、ブラウザー統合テスト15件を確認済みです。初版では実マウスによる移動・拡大縮小・回転も確認しました。
Neo実画面で背景＋透過キャラ2枚を合成して標準i2iに送り、768×768、20 steps、Denoising 0.3で生成完了を確認しています。

通常のimg2img向けです。PSD入出力、切り抜き処理、マスク生成・局所修正は含みません。
生成後の顔・服・構図の維持度はモデルとi2iの設定によって変わります。
Neo以外のWebUIおよび将来のForgeCanvas変更への互換性は未検証です。

開発用の状態テストは `node --test tests/state.test.cjs` で実行できます。

## v0.1.1の修正

Neo標準のサイズ取得が編集用canvasの表示サイズを拾う問題を修正しました。DOM上で標準ForgeCanvasを先に配置し、レイヤー編集はその下へ移しました。本体のサイズ取得関数は変更していません。
初期化と生成サイズの自動同期を追加。状態テスト10件・ブラウザー統合テスト15件に加え、実Neoで標準サイズ取得の628×387→768×768、初期化・undoを確認しました。
更新前のページには古いJavaScriptが残るため、編集を保存してからページを再読み込みしてください。
